# LogiNote

以本地笔记为基础，将学习规划、个性化教材、复述复盘、简测、个人认知图谱与模拟练习连接起来的 AI 学习工作台。

LogiNote 不只是替你整理资料：它希望帮助你看清「准备学什么、哪里还没理解、自己形成了哪些认识，以及能否把知识用于实际情境」。

当前桌面版本：**1.1.1**。主要交付 Windows 安装包；社区平台正在独立开发，移动端处于交互原型与架构设计阶段，尚不提供正式的 iOS / Android 客户端或私人数据自动跨端同步。

## 快速开始

1. 从本项目 [Releases](https://github.com/GlimmerElve/LogiNote-Chinese-version-/releases) 获取 Windows 安装包，安装后打开 LogiNote。
2. 在设置中配置模型服务商、Base URL、API Key 和模型名称。基础笔记与本地数据管理不要求调用云端模型；AI 工作流需要可用的模型服务。
3. 创建学习计划，设定个人周预算、本计划每日投入和学习日，再确认项目草图。
4. 打开当天的叶子项目，生成学习任务，补全关联知识点，并按需准备教材与参考资料。
5. 在阅读、简测、复述、复习和场景练习之间循环，把发现的理解缺口继续带回笔记。

支持 OpenAI 兼容接口（默认配置为 DeepSeek）、Anthropic Claude、Google Gemini 和 Ollama。请使用服务商实际接受的模型标识；配置 DeepSeek 或其他模型，不代表所有工作流都会自动联网搜索。

## 核心能力

### 学习规划：围绕叶子项目安排学习

- 用项目树、日期、里程碑与验收目标组织学习，而不只生成待办清单。
- 本计划的「每日投入」作为叶子项目的默认学习时长，单个叶子项目可另行调整。
- 个人周预算由所有计划共同使用；周负荷同时考虑叶子项目和独立执行事项，避免重复计算已包含在同日项目学习中的任务。
- AI 规划可区分核心内容与后续扩展。「核心 20%」是一种优先级取舍方法，不是严格的节点或课时比例，也不保证学习 20% 就获得 80% 的效果。
- 可选择联网补充课程结构和先修信息；联网失败与 STORM 研究的处理方式不同，规划支持降级继续，不应因可选搜索失败而完全阻断。

### 个性化教材：从项目任务到可阅读内容

- 根据项目目标、学习任务、知识点笔记和可用资料准备教材，保留章节与参考来源。
- 资料可绑定项目；子项目可使用当前项目及逐级父项目绑定的本地资料，不默认混入兄弟项目或其他计划的资料。
- 知识点、教材、用户复述、个人认知与参考资料分别管理，避免把教材示例当成用户真实任务或个人观点。
- Agent 可查询生成状态、准备生成、继续任务、定向修订章节及停止教材任务；实际执行受当前工具权限、任务状态与确认范围约束。
- 没有绑定资料时，不把全库搜索或资源统筹当作必经步骤；是否使用绑定链接或联网补缺，取决于本次生成配置。

### 简测卡片：检查理解，而不只检查是否记得词句

- 基于知识点正文和可用参考材料生成定向短题，围绕「概念、判断、推理」的具体判据检查理解。
- 通过比较、反事实、诊断、预测、构造和证据缺口等题型，帮助发现表面熟悉但尚不能应用的内容。
- 逐题反馈，指出仍需补齐的理解和证据；未实际考查、资料不足或使用辅助作答的部分，不强行认定为独立掌握。

简测、掌握度和学习画像是学习辅助信号，不是客观能力认证，也不能替代对答案、来源与学科正确性的人工核对。

### 个人认知 RAG：整理你已经表达过的理解

资料库回答「参考材料说了什么」，个人认知库关注「我当时怎样理解、相信或解释这件事」。两者不是同一个知识来源。

- 从已保存的用户复述、复习回答及其绑定的分析结构中收录认知，保留来源和原始表达。
- 不把普通教材正文、AI 诊断或任意项目图直接当成用户已经内化的认识。
- 在独立认知窗口中查看认知块、活动内与跨活动关系，检查孤立节点、断链及关系是否合理，并在图谱上整理。
- 专用认知助手可以查询、讨论和准备变更；新增、修改内容或条件、删除、建立或调整关系，须先预览具体变更，再通过确认卡提交。普通聊天中的「我意识到……」不等于已授权写入。
- 保留修改与来源记录，便于回顾认识如何变化。记录的是用户表达过的理解，不意味着该观点已经被证明为普遍事实。

### Agent：通过工具协助完成学习工作

- 查询和操作笔记、项目、计划、学习容量、知识点、资料绑定及教材等业务对象。
- 支持多个对话标签，分别保留会话与工作对象；标签绑定的对象可通过「使用当前页面」重新指定，不应假定所有标签始终跟随当前页面。
- 提供运行、排队、待确认与停止等状态，以及可调整的工具调用预算。
- 多标签不等于所有工作流无限并行：共享草稿、审批、任务和写入仍有所有者与并发边界。
- 通用助手与专用认知助手的工具范围分离；不能把 Agent 理解为可任意执行系统命令、修改任意文件或绕过确认的程序。

### 笔记、复述与复习

- **双向链接**：支持 `[[笔记标题]]`、`[[原名|别名]]`，以及知识点笔记、反向链接和图谱导航。
- **编辑与阅读**：Markdown、富文本、源码编辑及公式、图表和结构化内容展示。
- **心流学习**：专注学习、白噪音、定时提醒与用户复述；本地语音转文字可辅助记录。
- **复盘分析**：围绕用户表述整理论证结构、理解缺口和后续学习方向。
- **间隔复习与画像**：复习调度、对话式复习、学习记录与长期画像；区分单次活动证据与长期观察。

### STORM 式研究：先取证，再做多视角分析

研究流程为：联网证据 → 多视角分析 → 矛盾图谱 → 综合简报 → 模拟同行评审。

优先使用已适配的搜索 API，否则尝试隔离网页检索。没有有效证据时暂停，不静默生成没有检索依据的研究报告；阶段笔记保留实际来源链接、检索时间与材料范围。

这是项目自己的 STORM 式工作流，不代表完整集成官方 STORM 系统或获得真实同行评审。网页节选、论文摘要与预印本不等于完整、已同行评审的研究；检索时间不等于发表时间，也不保证覆盖全部最新成果。研究会向检索服务发送主题，可能产生搜索及模型费用。

### 模拟场景：S2 插件与 H5P

**S2 交互包 / 通用画布（试验）**

- 在「学习 → 场景模拟 → 通用画布（试验）→ S2 交互包 → 导入 / 更新」安装 ZIP，为场景选择组件、参数与连线。
- 安装新版本后无需重启即可为新场景使用；新旧版本并存，旧场景与运行中调用仍绑定原精确版本，不自动迁移。
- 同版本不同内容拒绝覆盖；插件可提供本地计算和经宿主桥调用的模型能力，用户与 Agent 共用公开搭建规则。
- S2 是可信本地 JavaScript 插件，不是不可信代码沙箱。仅导入可信来源的包；目前没有正式在线插件市场。

开发者从 [S2 开发指南](docs/scene-s2-plugin-developer-guide.md) 开始；字段与边界见 [接口参考](docs/scene-s2-plugin-api-reference.md)，随包资料见 [v2 物料协议](docs/scene-s2-package-materials-v2.md)。

**H5P 本地互动内容**

- 导入可信、运行依赖完整的 `.h5p` 包，在独立沙箱窗口播放；窗口不提供应用 preload、笔记或模型接口，禁止外部网络请求。
- 每 10 秒及正常关闭前保存内容类型提供的状态，也可手动保存；再次打开可恢复已提交的进度，但不是所有内容类型都支持续玩。
- 不自动下载缺失依赖；当前不提供 H5P 编辑器、Agent 制作或操控、社区发布。外链媒体及必须联网的内容不可用。
- 当前包上限 128 MiB、单文件展开上限 32 MiB；要求高于核心 API 1.28 的包暂不启动。版本可接受整数或严格十进制数字字符串，不放宽路径、CRC 和范围检查。
- 自报分数、完成状态不直接写成掌握度或个人认知；包结构校验也不等于脚本安全审计。

`h5p-standalone` 播放器按 MIT 许可分发，第三方场景、内容库和媒体仍须分别遵守作者许可。

## 1.1.1 近期体验优化

- 长教材按阅读区域与内容分段处理，收起的答案延迟挂载，减少初次加载与滚动时的前台计算。
- 稳定编辑器插件与实例，减少输入过程中重复解析和整库计算；隐藏页面保留编辑器及撤销、重做记录。
- 纯正文自动保存不再触发所有页面与侧栏整体刷新；标题、链接和任务等实际变化仍正常同步。
- 复用侧栏目录结构，关闭的搜索窗口不扫描整库；打开搜索仍可检索最新正文。
- 减少启动时重复读取整库，数学计算服务按需启动；保留自动保存、失败重试、退出保护与后台任务恢复边界。

这些是已实施的优化方向，不承诺在所有设备、超长笔记或第三方可视化内容上完全消除卡顿。离线回归、浏览器夹具、完整桌面交互和安装版验收是不同范围的验证。

## 备份与换电脑

1. 在「设置 → 本地数据与备份 → 打开目录」确认当前实际数据路径。
2. 完全退出两台电脑上的 LogiNote，先备份目标电脑的已有数据。
3. 将旧电脑实际数据目录的**完整内容**复制到目标电脑实际使用的数据目录，而不是程序安装目录；不要多套一层文件夹。
4. 打开目标电脑的软件，核对数据路径、笔记、资料清单与个人状态。

除 `vault/`、`user-state/`、`documents/` 外，还应保留：

- `rag-index/`：包含资料清单、解析与论证等数据，不能整体当成可丢弃缓存。
- `scene-interaction-packs/`：已安装的 S2 精确版本包；只迁移场景配置不等于迁移了插件代码。
- `h5p/packages/`：原始 H5P 包；个人进度在 `user-state/h5p/`，对外分享包时不要附带个人进度。
- 根目录下的 `note-embeddings.json`、`textbook-reference-embeddings.json` 等文件（如存在）。

不要照搬旧电脑主目录 `.logi-note/storage-config.json` 中的绝对路径锚点。JSON 笔记导出不等于完整备份；最稳妥的方式是复制整个实际数据目录。

**漏迁移资料清单**：使用「设置 → 本地数据与备份 → 扫描并恢复」，扫描 `documents/` 中未登记的文件，确认后补录到「待整理」。不会覆盖有效清单、修改原文件、自动解析或调用模型，也不能恢复丢失的原名称、分类和项目绑定。损坏的清单不会被扫描覆盖，应优先从原电脑恢复；需要索引时再到资料详情中建立。

**H5P 进度异常**：场景仍保留在库中，可通过原生确认执行「备份进度并重新开始」，原记录保留在 `user-state/h5p/backups/`。强制退出或断电仍可能丢失未保存的部分；有恢复机制不等于任意进程都能从任意位置无损续跑。

## 技术栈与源码结构

- **桌面**：Electron 35，主进程 / preload / IPC 与独立计算 Worker。
- **界面**：React 19、TypeScript、Vite 6、Tailwind CSS 4。
- **编辑**：MDXEditor / Lexical 富文本编辑，CodeMirror 源码与代码编辑；MDXEditor 不是 CodeMirror 内核。
- **检索**：`@xenova/transformers`、ONNX Runtime、本地 `paraphrase-multilingual-MiniLM-L12-v2` 嵌入模型与文件索引。
- **语音与数学**：SenseVoice / sherpa-onnx 本地语音识别，Python / SymPy 数学计算与本地资料解析。

```text
src/
  components/          笔记、计划、教材、简测、认知与场景界面
  services/            Agent、RAG、认知、学习记录与业务服务
  electron/            主进程、preload、IPC、本地服务与计算进程
  workflows/           AI 工作流与提示词
  interaction-packs/   预置 S2 交互包源码
apps/                  独立社区网站与 API 工程
packages/              社区等共享协议与模块
examples/scene-packs/  插件开发示例
docs/                  功能协议、开发指南、阶段设计与验证记录
scripts/               构建、验包与专项回归
models/                本地语音及嵌入模型资源

release/               打包依赖和历史构建产物
```

### 从源码运行

建议使用已验证的 Node.js 22 与 npm，在项目根目录的普通 PowerShell 中执行：

```powershell
npm.cmd ci
npm.cmd run electron
```

`electron` 会依次构建前端、编译 Electron 并启动应用。`start:electron` 只启动已有构建，不会更新前端。当前没有 `npm run dev` 脚本；不能用浏览器预览是否正常代替桌面 IPC 验证。

按所需能力准备额外依赖：

- Python 3 与 `python/requirements.txt` 用于源码运行的数学计算和资料解析。
- 语音源码运行另需 `numpy`、`sherpa-onnx`、`websockets`、PyAudio，以及 `models/sherpa-onnx-sense-voice/` 下的模型、`tokens.txt` 和 VAD 模型；这些语音依赖不全在上述 requirements 文件中。
- 本地嵌入模型应位于 `models/Xenova/paraphrase-multilingual-MiniLM-L12-v2/`。桌面检索不会在缺失模型时自行下载。
- AI 功能在应用设置中配置服务商。无需为了使用桌面客户端，把真实 Key 写进仓库配置或 README。

模型与预编译后端可能不包含在干净源码克隆中；安装版包含的资源不能视为源码环境已经具备。

### 开发检查

```powershell
npm.cmd run lint
npm.cmd run check:note-snapshot-isolation
npm.cmd run check:mdx-editor-runtime
npm.cmd run check:sidebar-projection
npm.cmd run check:application-shutdown
npm.cmd run check:scene-pack-install
npm.cmd run check:h5p
npm.cmd run check:installer-build
```

`lint` 当前执行 TypeScript 类型检查，不是 ESLint。`npm.cmd run` 可列出更多专项回归。不同脚本的环境需求和写入范围不同，执行前应阅读相应脚本；不要把任意测试指向真实私人资料库。

`npm.cmd run check:editor-save-isolation-browser` 使用真实 Chrome、已有开发 Playwright 和合成数据，验证保存、隐藏恢复、Agent 焦点切换与撤销 / 重做；业务外壳经过测试替换，不等于完整 App 或安装版性能验收。

H5P 真实包回归需要自行准备未改动的 `fill-in-the-blanks-837.h5p` 与 `true-false-question-34806.h5p`：

```powershell
npm.cmd run check:h5p-real-native -- "D:\H5P测试包目录"
```

默认包目录为 `.ui-preview/h5p-real/`。脚本校验固定 SHA-256，在临时目录通过真实 Electron 检查导入、播放、多窗口保存隔离、新进程恢复与继续作答；文件选择与信任确认使用测试替身，不自动下载，不读取真实学习库。结果和截图保存在 `.ui-preview/h5p-real/acceptance/`。这两个包的验证不能代表所有 H5P 内容类型均已通过；示例来源为 [填空题](https://h5p.org/fill-in-the-blanks) 与 [判断题](https://h5p.org/true-false)，须遵循各自许可。

## 数据与隐私

桌面端以本地数据目录为主，安装目录与学习数据目录分离：

- 笔记正文位于 `vault/notes/`，结构化元数据位于 `vault/metadata.json`。
- 复习、画像、个人认知、Agent 会话与任务等个人状态位于 `user-state/`。
- 上传原文件位于 `documents/`；资料清单、分块、索引及解析数据位于 `rag-index/`。
- 桌面笔记向量等数据使用本地文件，例如 `note-embeddings.json`；浏览器回退的存储方式不能代表完整桌面存储。

本地优先不等于所有 AI 功能离线。语音识别与向量检索可本地运行；选择远端模型时，该工作流所需的笔记片段、复述或参考材料会发送给你配置的服务商。联网检索也会发送查询主题。模型与搜索费用、数据处理规则取决于相应服务。

模型密钥与个人学习记录可能包含在设置及备份中，请勿提交 `.env.local`、公开真实数据目录，或将私人备份当作可分享资源上传。资料、教材和场景包是否可以分享，还取决于版权与授权。
