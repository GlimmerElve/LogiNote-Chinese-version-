# 个性化教材阶段四实施记录

2026-10-06。本阶段接通教材的共享格式契约、真实笔记编辑器导入导出、项目教材阅读与心流阅读。只改教材链路，资源四标签页推荐与知识点概念补全沿用原逻辑。

## 入口与内容隔离

有受管教材的项目笔记可在“编辑笔记与复盘”和“阅读教材”之间切换。编辑器保留原有任务、折叠复盘框及论证图入口；阅读页和心流默认只展示教材区域，既不把个人复述当作教材，也不将整篇教材预填到新复述会话。边界损坏时明确提示，不能猜测剩余正文属于教材。

阅读器按稳定项目 ID 与教材修订保存个人章节锚点及滚动位置。目录支持键盘跳转，重新进入同一修订优先恢复章节内的精确滚动位置，只有缺少有效滚动值时退回章节锚点；异步图示改变高度时在有界初始化窗口内恢复，用户滚动立即接管。退出时写回最后捕获的位置。进度通过窄更新合并当前 notes，不使用保留的心流旧快照覆盖新正文，不改任务完成、掌握度、认知观点或更新时间，也不触发正文重新索引。阅读记录不进入可分享教材。

浏览器验收发现原先每次计时或进度更新都创建新的 Markdown 渲染组件，导致图示反复卸载重建、页面闪烁和来源弹窗消失。本次改为稳定组件与上下文传递，保持图示及弹窗实例；来源弹窗使用既有全局键盘归属和焦点恢复。心流问题卡只在项目 ID 改变时初始化，不再因阅读进度更新清空尚未保存的问题。

## 共享格式与编辑保存

基础语法使用真实 Markdown AST、GFM 与数学扩展，不靠标题或围栏字符串替换组装页面。编辑、生成校验和阅读共用受控块白名单：

- 公式：`$…$` 与多行 `$$` 使用现有 KaTeX 只读渲染；点击后复用 MathLive 编辑，失焦或 Enter 暂存，Escape 放弃。兼容原工具栏独占段落的单行双美元模板。MathLive 字体 CSS 随应用打包，不依赖公网字体目录。
- Mermaid：仅支持 flowchart、sequenceDiagram、mindmap。按需加载，限制长度、节点和边，关闭 HTML 标签与交互，禁止初始化指令、URL、回调和任意样式。渲染出的 SVG 还经过二次检查；错误展示原始源码，不执行脚本、不丢图块。
- 图表：`chart` 围栏使用限定 JSON，不接受原始 ECharts option。仅 bar、line、pie，1–40 个标签、1–6 个等长有限数值序列。资料数据必须引用本教材已采集来源；模拟数据明显标注“教学示意”，同时提供可读数据表。引用存在不等于数据已被权威验证，仍需核对原文和口径。
- 代码：原代码围栏在编辑器中可编辑，阅读端按需高亮并复制。未知语言仍保留源码及语言，不执行 Python、JavaScript 或终端命令。
- 表格、脚注与注释：GFM 表格及 `[^编号]` 保存重开保留；脚注定义提供源码编辑。`textbook-tip` 为提示、定义或警告；`textbook-answer` 默认折叠，支持文字、基础 Markdown 与公式，不允许嵌套执行块、外部链接或项目任务。复杂代码答案保留正常 Markdown，不为折叠而静默删减。
- 图片：`textbook-image` 只能使用已授权素材 ID，不能传 URL、任意路径或 SVG。当前从已解析本地 Markdown 的内嵌 PNG/JPEG/GIF/WebP 读取，单张不超过 1 MiB、边长 4096、像素数 400 万，并校验真实容器及实际栅格尺寸。GIF 逐帧矩形不得越界，最多 40 帧，累计画布像素不超过 1600 万；动画 WebP 明确拒绝。源文件版本、原文块或编号变化时拒绝，不自动下载替代图片。

特殊块在真实 MDXEditor 中注册导入、导出和源码编辑插件，不只是阅读器支持。原文、围栏语言、公式节点、脚注、教材区域与学习记录分别保存。格式损坏只影响该块，保留源码供修正。普通笔记与原图入口继续使用原有编辑器。

新依赖固定版本：Mermaid 11.12.0、ECharts 6.0.0，及 Markdown 数学/GFM 和 CodeMirror 语言扩展。复用已安装的 MathLive、KaTeX、MDXEditor 和 CodeMirror，不增加第二套公式编辑器或爬虫框架。

## 来源与本地图片指针

上传资料来源保存文档 ID、版本、原文块和精确字符范围。点击 `[L#]` 打开限域深读原文，支持分页；旧教材缺精确坐标时提示打开源文件，不拿检索摘要冒充原文。知识点 `[N#]` 按稳定 ID 和标题、正文、别名版本核对，删除或改变后明确失效，不读取内部教材任务草稿。来源弹窗遵守全局弹窗键盘与焦点约束。

图片只在清单保存来源指针，模型输入省略图片字节并说明“仅供显示，不作为已理解的图像事实”。生成校验确认图表来源、图片素材和注释文本与本章授权范围一致。图示标签、图表标题/标签/序列名、提示与答案标题/正文、图片说明都属于教学展示文本，解码 JSON Unicode 转义和 Mermaid 数字实体后同样检查引用和私人原话；普通程序代码不冒充正文事实引用。Mermaid 语法不当 Markdown 检查，合法子程序节点不误判为 wiki 链接，隐藏注释及图示本身不能替代邻近正文必须提供的事实引用。只有完整原文块可形成稳定图片编号；未经本地采集的引用仍显示不可用。PDF/Office 图片提取、扫描件 OCR 与复杂公式解析在阶段五，不宣称本阶段已支持全部附件图片。

## 验证范围

新增格式、编辑器、阅读/图片脚本，分别验证共享 AST/受控 schema/SSR/真实深读 client、真实 Realm 与 Lexical 导入导出及节点修改、窄阅读状态和实际临时磁盘重载。本地资料和模型仅使用合成夹具，不访问用户笔记库或云端模型。

隔离浏览器入口 `scripts/textbook-ui-check.html` 挂载真实编辑器、共享阅读器与 FlowMode，不挂载 App 或用户库。已在浏览器验证三类图示和统计图表、MathLive 编辑、多格式保存重开、脚注修改、代码复制、引用弹窗与 Escape 焦点返回、折叠答案、本地图片解码。心流计时连续更新两分钟时图示实例不变、来源弹窗保持打开，退出会话保留独立复述和新增问题卡；编辑/阅读切换后恢复相同的章节内滚动值（1068 px）。该入口不是用户正式功能页，也不将浏览器夹具验收描述为原生 Electron 全链路验收。

格式检查 10 组、真实 Realm/Lexical 编辑往返检查 4 组、阅读状态与本地图片检查 5 组、生成发布检查 24 组通过。后者新增真实目录/图片采集、模拟模型多格式章节、生产发布适配器、实际临时磁盘重载与展示文本负向门控。合同 12 组、记录 13 组、物料 11 组以及既有 Agent/资源/学习完成检查通过；类型检查、Web 与 Electron 构建通过，已有 ONNX eval/大分块和静态/动态混合导入构建警告保留。阶段零审计仍精确保留两项旧无来源教材缺口，不将预期缺口匹配视为完整功能验收。

测试页编辑模式曾遗漏正式 NoteEditor 已使用的 `h-full` 约束，导致长内容被外层裁切。已补齐并实际滚动到编辑器末尾（2524 px）及阅读器末尾（1948 px），这项修复只改隔离夹具的布局。
