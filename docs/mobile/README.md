# LogiNote 移动端 · 第一阶段交付

交付日期：2026-10-30。范围：产品方案、同步架构、官方规则与开源参考、可操作原型。真实私人同步、AI 服务、移动安装包和商店发布留待后续阶段。

## 查看原型

已启动的本机地址：[LogiNote 移动端原型](http://127.0.0.1:5182/design/mobile-prototype/index.html)。该服务只监听本机，不是手机可直接访问的公网服务；浏览器可以调整窄屏查看移动布局。

在项目根目录重新构建和启动：

```powershell
node node_modules/vite/bin/vite.js build --config scripts/vite-mobile-prototype.config.ts
node node_modules/vite/bin/vite.js preview --config scripts/vite-mobile-prototype.config.ts
```

第一条命令生成独立产物 `output/mobile-prototype/`；第二条命令启动本机 5182 端口。该配置不启动桌面 App、资料库迁移、社区账号或 AI 服务，未修改原有应用入口和构建配置。

## 交互范围

- **发现**：一次一张内容卡片，左右滑动或点击切换；保留搜索、查看来源与轻量收藏。
- **练习**：逐题卡片，选择并提交后显示解析，点来源查看资料；演示作答不写入真实掌握度。
- **复述**：卡片上点击后弹出极简气泡，仅有编辑框、“按住说话”、保存和关闭图标；来源在内部保留。长按演示语音、松手结束、上滑取消；点击编辑框直接打字，保存后继续阅读。
- **记录**：按日期分组、搜索、点开详情及返回来源；继续草稿或点加号打开输入气泡。
- **消息**：会话列表、搜索、固定底部输入区；草稿按会话保存。演示消息不发送给真实用户。
- **计划**：今天/全部切换、日期分组、勾选及打开任务；底部弹层生成草案与改期，确认前不改原计划。冲突演示开关在同步设置中。
- **头像/同步**：模拟离线/回执，隐私及 AI 同意/拒绝/撤回流程，账号删除与协议设计说明。
- **工作区**：宽屏保留架构与实施路线入口，窄屏只显示移动界面。

数据仅写入浏览器 `loginote.mobile-prototype.v1` 命名空间；异常原串在覆盖前备份到同前缀 `.recovery.*`。清理或更换浏览器/站点会影响这些本机演示数据。原型不提供真实的云备份或离线应用安装；“模拟离线”验证的是已经打开页面后的本地交互，不等于完成离线冷启动、后台同步或真机验证。

打开气泡不自动弹键盘；点击编辑框才取得输入焦点，由手机系统管理默认键盘。没有单独的“打字”或“键盘听写”模式按钮，也不显示气泡标题、来源、字数和说明提示。原型只演示按住语音的状态，不实际录音或调用浏览器语音识别，不填入虚假的转写文字；正式语音需另接原生能力。

## 验证结果与复现

已通过独立 TypeScript 检查、Vite 生产构建，以及真实 Chrome 浏览器交互检查。检查范围包括单卡按钮/键盘/触摸切换、原地复述气泡、草稿来源保留、编辑框焦点、弹出动画与减少动态效果；同时保留 320/375/390/430/768/1440px 布局、题后解析、计划确认/冲突、聊天及保存失败恢复等检查。本轮长按状态与极简气泡的结果以验收 JSON 为准。真实语音识别、权限和手机键盘仍需 Android/iOS 真机验证，不能由 PC 浏览器通过替代。

证据：验收结果、卡片发现页、复述气泡、动画气泡、完整工作区。

浏览器检查复用已有 Playwright 安装（不自动下载/安装依赖）；`LOGINOTE_BROWSER_MODULES` 指向包含 `playwright` 包的 `node_modules` 目录，本机需有 Chrome：

```powershell
$env:LOGINOTE_BROWSER_MODULES='实际已有的 node_modules 绝对路径'
node scripts/run-tsx-safe.cjs scripts/check-mobile-prototype.ts
```

测试使用独立浏览器上下文、临时本机预览端口与合成数据，不读取真实 LogiNote 资料库。当前源码变更后，应先重新构建再测试。
