# 交互教材验收集

这套验收集使用固定的合成材料，不读取用户笔记、画像或资料库。案例和逐项期望见 [`scripts/fixtures/teachable-acceptance-cases.json`](../scripts/fixtures/teachable-acceptance-cases.json)。目前包含 17 个案例，覆盖数学（含积分面积）、概率、统计、物理、化学、计算机、心理学、流程和三维形体，以及参数缺失、冲突和缺少参考几何的情况。自动检查和真实模型测试覆盖的范围见下文，不能把案例数量等同于全部实测通过。

## 运行

在项目根目录执行：

```sh
npm run check:teachable-acceptance
```

默认只运行离线自动检查。要检查真实 Electron 交互、心流和分享，运行：

```sh
npm run check:teachable-acceptance -- --desktop
```

要额外调用当前配置的 DeepSeek，运行：

```sh
npm run check:teachable-acceptance -- --desktop --live
```

`--desktop` 先构建当前前端；构建失败时跳过桌面测试，避免误测旧产物。`--live` 使用与离线验收同一份固定合成案例，各发一次请求，共 9 次，不自动重试；使用项目当前配置的模型，可能产生费用。联网结果、生成文件路径及用量记录在该次报告中，不发送用户内容。每次报告保存到 `build/teachable-suite/run-*/report.json`，并生成可填写的 `review.md`，不会覆盖以前的验收记录；报告记录案例文件的 SHA-256。桌面测试使用独立数据目录和合成模型，不操作真实笔记。

## 如何解读

- **案例选型与确定性结果**只核对注册组件的选择、部分固定数值、冲突及需要参考几何的拒绝；它不声称每个案例的所有人工期望均已验证。
- **离线自动检查**覆盖已有本地组件、来源边界、生成/恢复、局部修复与分享。桌面层额外操作隔离渲染器、主题、心流标签、重开和离线附件。
- **真实模型状态 `generated`**只表示该次生成完成；模型有波动，生成成功不代表教学、视觉或学科正确。生成时若无法连接或输出截断，报告记为失败，不自动重试。
- 同时启用 `--desktop --live` 时，每个成功生成的结果还会在隔离桌面环境运行基本检查并导出 `figure-portable.html`，报告列出 `safePreview`。原始 `figure.html` 是模型生成的未隔离片段，仅作为测试输入，勿在应用外直接打开。运行告警、交互或重置无法确认、诊断不可用或截图失败时报告为 `needs-review`；这些现象需要进一步判断，不能直接当作故障或通过。
- 每个案例的 `teachingReview`、`visualReview` 初始是 `not-reviewed`，不可根据脚本运行成功改成通过。学科正确性也需要独立复核。
- `teachable-chemistry-clipped.html` 是合成教材的模型生成快照，仅作为隔离沙箱的回归输入；它有已知的柱形越界，不应视为可发布教材或在应用外直接执行。

## 人工教学与视觉验收

对每份生成物记录：案例 ID、模型和版本、验收日期、教材/假设、使用设备及窗口、结果和可复现的问题。分别标记**通过、失败或未检查**：

1. 教学目标是否明确；预测题是否覆盖目标而非只问无关计算；解释、反馈与迁移是否对应实际操作。
2. 数值、图形、坐标、文本、来源和限制条件是否一致；测试零点、两端及中间状态。对随机案例区分样本和理论。
3. 实际观看浅色、深色及窄窗口画面；检查图示、公式和标签可读，真实使用键盘和指针，检查重置。
4. 关闭并从资源栏重新打开、重启后恢复；检查失败记录和不重复请求；在断网条件下打开分享包及其相对链接。
5. 针对长教材和多个图，在目标设备测滚动、交互延迟和资源占用；记录测试规模和机器，避免把单机结果当作普遍保证。

实际学习效果需在自愿参与的学习任务中单独验证：给参与者目标，先预测，再操作并复述原因，最后给一个未见过的迁移情境；记录是否需要提示以及错误类型。自动检查、模型复核和人工看图均不能代替这一步。未经许可不收集真实笔记或个人画像。
