# 单窗口精简语义块协议（v5，隔离实验）

## 目的与边界

避免实验设定、提问和回答比例成为孤立“事实”。同一情境优先保存为完整content内容块，只有必须拆开的关键语境才复用prerequisite。没有新增contains、sequence等关系，三种论证关系保持不变。content是中性内容兜底，不是新的图尔敏角色，也不意味着已证实。

本轮仅调整scripts中的窗口实验、原文绑定、只读预览。不改本地窗口划分，不做跨窗口身份匹配，不修改生产抽取提示词、向量索引、评分、用户画像或AgentSkill。旧v4提示词、解析器和历史模型响应不改写。

## 处理顺序

1. 使用现有窗口与before/core/after范围，不携带全篇或历史模型输出。
2. LLM只解构标注、确定必要关系。完整情境可含设定、问题和对应结果的多个原文spans；不同情境不能混合。
3. 本地严格绑定每个span和关系引用的真实原文位置，拒绝额外字段、未知端点、重复ID等，不猜语义和补边。
4. 展示内容中的spans按原文坐标排序。保留模型原始spans顺序和响应，不修改语义、成员或连线。
5. 独立做原文语义验收。绑定通过及句子被引用，不保证完整覆盖、合块正确或来源归属完整。

## 验收标准

- 每个情境包含其必要设定、变更条件、问题对象和对应结果；假设、疑问等语气不能变成既成事实。
- 比例必须能确定对应的情境和问题，两个情境的比例不能互换。
- 共享研究归属、样本信息等必要背景须在相关块中保留，或用必要理解前提连接到背景；仅在页面上另显示背景不算已完成。
- 一个完整内容内部不必逐句建边，彼此完整独立的块不强求互连；连线数量不作为通过标准。
- 只有拆开后会失去对象、条件或概念含义的依赖才连prerequisite；说明性案例不能冒充support。
- 不建立顺序/包含目录网，不用全图连通率替代语义检查。
- 所有原文与边的证据能追溯，无人工修复模型响应，无生产写入。

## v6：只增加关键展开关系

窗口5的N1首先是实验目的/整体说明，不只是研究来源。新增elaboration：整体说明、研究目的或一般描述→具体情景/实例/分项。即使情景内部完整，仍保留这项独立语义关系。研究目的不当作已得出结论，不将结果反向连向目的充作support。重复的背景依赖不另加线，另有独立定义/条件需求时才加prerequisite；不强求所有关系互斥或全图连通。

只增加一个关系类型，未增加contains/sequence。v5提示词与其默认解析器仍保留；v6显式使用`--elaboration --window 5`，按manifest选择新提示词、解析模式与展示标签，不覆盖历史响应。role与锚点格式不变。v6纯合成教学示例有一个研究目的和两个完整情境，明确示范两条展开线，没有预填真实AP资料的节点答案。

本地测试：`node --experimental-strip-types scripts/check-ap-window-elaboration.ts`，10项协议/绑定/图转换检查，零模型请求。其他角色和关系的稳定性不能仅凭这些人工构造检查认定。

2026-10-08 v6窗口5实际复测：同一输入hash，1次DeepSeek请求，无重试。3个content节点、2条elaboration（N1→N2、N1→N3），原文证据绑定全部通过，两个情境各自保留设定、问题和33%/67%、58%/42%。当前单窗口目的与情境展开要求核对通过；仍不代表全篇抽取、四类关系稳定性、跨窗口或生产RAG链路已通过。

## v6窗口6、7迁移检查（2026-10-08）

当前同一提示词分别发送窗口6、7，共2次DeepSeek请求、零重试，原文绑定均通过、每个core句子至少有一处引用，正式索引/认知库/画像/分数零写入。原始响应独立保存，人工语义注释不改模型节点或关系。结果目录：`ap-windows-5-6-3kJ4oM`。

- 窗口6：11节点、9关系（6展开、3理解前提）。与旧v4相同输入相比，保留了先前遗漏的France Leclerc研究引导句，增加总述到三个账户说明的展开；实例不再全部归为claim。但三个基础定义由旧版分别保存变为合并N2，局部账户定义到自动参照评价主张的依赖遗漏；综合账户定义/实例合并N9、两公式合并N10的问题仍在。当前精确分块/依赖验收未通过。
- 窗口7：10节点、8关系（3支持、1质疑、2理解前提、2展开）。观察结果与解释分开，原价相同/同量节省等限定保留；观察差异→质疑一致预期的方向合理。但N6→N7将命名/指代当作支持；N10→N8/N9将后续实验条件误当成前文两个研究情景的总述，只有共享权衡措辞，不能满足整体→具体展开证据。关键关系语义验收未通过。

结论：窗口5的成功不能推广为各类窗口均已稳定。窗口6可观察到定义粒度退步；窗口7没有旧版同输入对照，不能称为已证实的回归。单次模型采样也不能证明新增展开规则是唯一原因。下一次提示词调整应限定命名/指代与支持、实验条件与具体展开的区别，并检查已规定的独立定义/公式拆分；本轮不再追加请求或自动改边。

用于复现的准备/执行必须显式携带`--elaboration --windows 6,7`，仍冻结每窗口一次请求上限；独占dispatch保护禁止重放。只读预览按batch所选窗口生成`/6`与`/7`，不会加载全篇到LLM或补造跨窗口边。
