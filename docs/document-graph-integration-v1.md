# 资料双 RAG 正式接入记录（2026-10-12）

## 已接通

资料页「处理下一批图谱」→ 本地阅读窗口（章节、过渡上下文、对应注释）→ 节点抽取 → 关系构建 → 原文复核 → 实体／节点映射 → 必要时本地跨图候选召回、结构保护修剪及模型核对 → 本地节点和实体向量化 → 来源绑定的图谱原子保存。

正式问答：正文与实体／论证入口融合 → 按入口排名追溯实际论证链 → embedding 重排与结构保护 → 带引用的平铺上下文。原有单次补检索机制保留。

## 版本和边界

- 节点 v2.3、关系 v2.7、复核 v2 的冻结基线在 `src/workflows/documentGraphStage1.ts` 至 `documentGraphStage3.ts`；测试检查与原冻结文件的一致性（忽略换行编码）。正式请求由 `documentGraphRuntimePrompts.ts` 组装：初抽保持原样，关系与复核阶段加入共享九类定义、核对口径和诊断分类，当前版本为 `document-graph-shared-types-and-gaps-v2`。实体阅读位置协议为 v2。
- 排名扩展 v4、embedding 修剪 v1 提升为运行时模块；测试与实验实现逐字段比较。
- 实体与跨图提示词是正式接口适配版，尚需真实模型验收，不能把本地测试当作语义认证。
- 每批最多 5 个窗口，通常不超过 6000 字符；单个完整窗口可达 12000 字符，超出则停止而非切碎。
- 每批 4 次模型请求，存在旧图且有跨图目标时最多新增 1 次。无自动重试。成功阶段在当前进程内保留，用户明确重试时复用；重启后只有已提交批次可恢复。
- 每批最多 8 个跨图目标，各最多 16 个候选；未召回、预算不足、原文歧义保留缺口，不伪造连线。当前方向为新批次查已保存前文，不声称能自动补齐所有前文向后文的引用。
- 指代只在实体抽取和独立原文复核的对象选择一致时作为局部提及保存；未复核指代不作为全局别名。不是完整 V3 指代登记工作流的全量迁移。
- 图谱上限 640 节点、1280 关系；有预算限制，不能声称任意长度资料均可完整解构。
- 正文/旧知识分片保留；新图不改掌握度、个人画像、认知写入或 AgentSkill 权限。

## 保存和安全

- 源码坐标恢复原文，不接受模型改写的正文。JSON、来源、ID、端点、共同前提、自环、同类闭环、回指台账落实均检查。
- 每批进度与图谱一起持久化。模型失败、来源变更、旧修订号、窗口计划变更均不得覆盖上一批。
- 模型、云端模式、知识层开关、资料库环境变化时停止；只在用户点击后开始模型调用。
- 已有但没有新版进度元数据的独立图不会被自动替换。
- `semanticCertified` 始终为 false；有支持不代表事实已经证实。
