## 个人记录与教材正文

`LearningReviewRecord` 使用稳定会话 ID。每次心流学习分别保存项目、根项目、实际学习时间、教材修订、复述、总结及原 `argumentDocs` 的图 ID。复述原文是首次暂存时的本次输入，不是另存一份音频或未编辑的完整 STT 流；用户编辑后的复述单独保存，明确清空也不会回退索引旧原文。

笔记正文只插入 `<LearningReviewBlock ... />` 引用。框默认收起，标题取学习时间，可重命名；展开显示本次复述、总结及原 `ArgumentBlockComponent`。用户修改标题、复述或展开状态后，图编辑回传不覆盖这些字段。同日另一会话另建框，同一会话保存重试不重复图或入口。原图数据、编辑器调度和质量发布门控不另建平行实现。

使用原生 `details` 与 `summary`，复用现有样式变量。已在实际 MDXEditor 中修正空格键被 Lexical 拦截的问题，验证 Enter 和空格展开收起、标题输入与 Enter 提交。原图编辑按钮获得键盘焦点时可见。

`TextbookManifest` 当前只包含项目教材身份、修订、区域与时间。受控 `TextbookBoundary` 节点使来源边界在编辑器导入导出后保留；读取和替换使用同一组原文坐标，不误改代码示例中的同名标记。正式发布入口、引用清单、内容哈希冲突检查和版本历史仍属后续生成阶段。

复述、迁移备份、折叠状态及预留阅读状态属于个人状态，不进入教材分享字段；`argumentDocs` 保持既有存储与分享规则。阅读进度字段已可保存，但章节定位和心流续读尚未接入。

## 保存和恢复

心流输入从空的本次会话开始。退出先等待会话暂存成功，再沿用知识点选择、掌握度评分和复盘分析。分析结果保存时从最新目标笔记合并图和记录引用，而不是回写旧整篇正文。重复点击有同步守卫，图编辑保存按原 ID 更新。

关闭分析或分析失败保留真实文本，不伪造结构图。取消后迟到的模型回调不能重新打开结果页；旧会话的评分结果不能改写下一次会话。后台保留的心流页尊重可见性门控，Esc 保存使用最新总结、问题、分析开关及学习时长。

桌面保存使用私有待恢复快照文件和串行写入队列。先保存可恢复快照，再写个人状态、正文和元数据；失败向调用方抛出，不由浏览器缓存冒充成功。启动或资料中心重读前恢复同一快照。这里是可恢复多文件事务，不宣称多个文件在操作系统层面同时原子提交。

重启时为未完成分析且缺少正文引用的暂存记录恢复可见入口，保留真实待处理状态；不会恢复用户主动移除的已完成记录入口。旧混合正文保留原位，并保存私有原文备份。不按日期、标题或邻近位置猜测旧复述和旧图的配对。

## 来源与任务边界

受管教材区域不进入个人复述素材，教材改标题、改正文后仍按区域分源。任务和图组件标记也不作为复述；当前有效复述来自个人记录，不包含框标题、分析总结或原图标记。个人素材仍为未确认、无事实证据资格，不自动进入确认认知。

教材中的演示清单和 `@due` 不形成真实任务或日程。代码缩进相对当前列表内容判断，不将四空格或 Tab 开头的合法子任务误屏蔽；真正缩进代码、列表内及列表项自身开始的围栏仍排除。排除示例时保留原行号，真实任务的稳定 ID 和勾选坐标不漂移。资源任务入口仅增加这个来源过滤，不修改四标签页、查询策略、自动配额、手工添加或偏好规则。概念补全实现未改动。

旧正文缺乏可识别教材来源时，仍不能可靠区分教材与手写复述。旧 `generatedContentBlocks` 的全文匹配排除在编辑后也仍有限制；本轮保留严格断言，不用标题猜测或删除旧内容来掩盖缺口。新增受管教材路径不依赖这种全文匹配。
