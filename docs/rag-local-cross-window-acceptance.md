## 本地处理与真实语义关系

1. 原始响应重新解码：按 readNodePass/readPresupposesPass 恢复两阶段响应，与冻结 nodes-draft/draft 一致，校验节点/响应/输入/来源版本哈希。节点文本和UTF-16原文片段再次绑定，原文件逐字比较未变。
2. 全局身份：文档版本、窗口、草稿哈希、局部编号共同定位节点。原文完全等价且角色兼容的视图建立同源映射；粗细包含只建来源视图。内部负号、小数点、百分号、运算符不被忽略；仅句末普通句号允许白名单变体。
3. 案例包：按研究介绍锚点与原文情景标签建立两组完整情景上下文。显式研究引用必须唯一；明确情景编号再过滤，不能仅凭“情景1”或作者年份全篇匹配。同源/案例导航不计作论证边。
4. 本地提出候选：使用明确实验回指、问题与结果、标准/快车时长、定义与公式操作数等有限模式，不按手写N编号加边，不读取验收期望或复核文件生成边。所有新边先为 candidate。
5. 独立助手逐条核对原文后写单独复核记录，绑定原图哈希。只读取 reviewed 语义边；保留 from 的共同前提组，节点预算不足不能拆散。深度/预算耗尽及未解指代明确报告缺口。
