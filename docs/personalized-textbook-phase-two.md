# 项目教材阶段二本地物料读取

验证日期：2026-10-06

阶段二已接入限定资料范围的目录、章节分页、邻近原文和引用物料包。资料先解析并保存可定位原文，再进入原有向量流程；向量模型缺失或索引失败，不妨碍已准备资料的本地深读。本轮没有开放教材生成或项目写入入口，用户画像、教学蓝图与批准发布属于阶段三。

## 本地读取与来源范围

教材读取接口要求明确传入 `allowedDocIds`。缺省范围、非法 ID、路径以及范围外资料均拒绝，不把空范围解释为全库。请求只使用资料库 ID，不接受任意文件路径。允许范围最多 256 个资料 ID，是单次读取的安全边界，不限制用户上传或手工添加资源的数量。

现有 `searchDocuments` 增加可选范围参数。显式范围在读取分块、知识分片及排名前过滤，而不是获取全库命中后再截取；知识层名称与别名也从范围内提及整理。不传新参数时保持原模式、模型调用顺序、结果上限、排序权重和每文档三条的基线。资源推荐的四标签、自动配额、手工添加和偏好策略，以及概念补全的标题和别名策略均未修改。

范围由调用方显式提供，尚未绑定 Agent 的用户批准记录。阶段三需把范围与目标项目、用户批准和生成任务快照绑定，不能将这一接口当作已经完成授权流程。

## 目录和完整原文

资料目录包括章节、层级、完整原文范围与格式专属定位。上级章节包含子章节，直到下一个同级或更高层级标题；无可识别标题的 PDF 按页组织，而不是猜测章节语义。目录和素材目录使用版本绑定分页，默认每页 40 项、最多 100 项。

原文可按章节、块或现有 RAG 命中读取。命中只有在分块坐标和实际原文一致时才能扩读；不匹配的旧命中需改用目录或重建索引。邻近块默认各两块，最多各十块。原文每页默认 8000 字符，最多 12000 字符和 80 个块；返回续读坐标、是否截断以及是否只读到部分块，不用预览片段冒充完整章节。

每条引用保留资料 ID、原文版本、块 ID、章节路径、归一化文本半开区间、原始定位及摘录 SHA256。定位沿用已有解析器：TXT 与 Markdown 字符范围、PDF 页码及可用包围框、DOCX 段落、PPTX 幻灯片与备注。新接口不向前端返回向量或原文件绝对存储路径。

## 解析状态和来源失效

`parseStatus` 与已有向量 `status` 独立保存。显式准备资料只运行现有文本解析器，不启动向量模型、LLM 或网页检索。新上传的可解析资料在原后台流程中先落地原文；旧缓存缺少原文件版本时需显式准备，不能自动视为可靠引用。

物料版本由原文件 SHA256、解析版本、归一化文本和块定位共同生成。解析前后校验原文件，深读时再次核对，组装结束再复核所用版本。删除、文件内容变化、重新解析后版本不一致，或损坏定位，均返回明确失效错误。读取原文件上限为 100 MB，不跟随资料文件符号链接；结构化原文另有文本长度和块数边界。

## 多格式素材和物料包

Markdown 围栏代码不再把内部 `#` 当作标题，代码缩进与表格空格保留。素材目录清点代码、表格、公式、图片引用和已有图注块。图片引用仅标为引用，不自动下载；Office 和 PDF 图片、扫描件 OCR、复杂表格结构及公式识别仍属后续解析增强。现有 MathLive 和 KaTeX 无需另装同类插件，但统一教材阅读端尚未接入。

`assembleLocalMaterialPacket` 按稳定项目 ID 汇集所选章节或命中，连续读取并校验摘录哈希，去重同一原文区间，保留引用与覆盖状态。默认总预算 72000 字符，最多 120000 字符及 16 个阅读目标；预算或分页安全边界耗尽时明确保留未读缺口。物料包标记原文为不可信指令内容，资料也不因被上传而成为用户确认观点。

物料包当前是内存中的本地原文集合，不是持久化教材，也不自动将缺口转换成在线搜索。本地资料是否符合学习目标、认知遗漏如何进入蓝图、内容是否充分以及模型引用是否合法，由阶段三质量门控实现。

## 验证结果

`check:textbook-materials` 的 11 组检查覆盖实际解析、服务与临时磁盘：范围拒绝、无向量模型直读、完整父子章节及尾部条件、目录分页、命中邻近块、原文包和预算缺口、摘录篡改、来源变化和删除、多格式定位、旧缓存及不支持格式、限域 RAG 和知识别名、80 块续读及组装末尾版本复核。

多格式测试使用合成 DOCX、PPTX 和双页 PDF。PDF 走既有 unpdf 兜底；此测试不验证桌面应用启动时注入的 PyMuPDF 脚本。前端 client 测试使用内存 bridge 调用真实主进程服务，不等同于原生 Electron IPC 人工验收。没有操作用户笔记库、调用云模型或下载新依赖。

回归通过：`check:textbook-records`、`check:textbook-contracts`、`check:textbook-baseline`、`check:resource-browser`、`check:rag-sources`、`check:document-parsers`、`check:rag-foundation`、`check:rag-semantics`、`check:rag-rebuild`、`check:knowledge-store`、`check:knowledge-retrieval`、`check:agent`、`check:agent-e2e`、`check:agent-interaction`、`check:agent-sequence`。类型检查、Web 与 Electron 构建通过，Web 仍有既有 ONNX eval 和大包提示。无来源旧正文的两项严格缺口不在本阶段修复范围；完整教材生成仍未实现。

## 下一步本地教材生成

阶段三在这些原文接口上接入用户批准、稳定目标项目、画像与认知证据、教学蓝图、章节生成、引用校验和原子发布。先使用现有可读本地文本、表格和公式形成生成闭环；保留既有复习入口和阶段一的折叠学习记录，不覆盖个人复述或论证图。
