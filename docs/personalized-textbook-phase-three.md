# 个性化教材阶段三实施记录

2026-10-06，已接入首次本地教材生成：用户在 Agent 确认后，系统读取限定资料与个性化证据，设计教学蓝图、逐章生成并复核，再写入稳定 ID 对应的项目笔记。已有教材默认继续阅读，不因跨天或未学完重复生成。资源推荐与概念补全沿用原流程。

## 使用入口

选中目标项目，在 Agent 中输入“根据本地资料，为当前项目生成完整教材并写入笔记”。Agent 先查询已有教材、关联知识点、资料元数据及当前根项目复习建议；复习使用既有入口，用户可接受或跳过，不插入教材正文。

默认物料范围是项目已绑定的本地资料和显式关联的知识点笔记。额外资料须先按文件名选择，确认卡片展示锁定文件、目标项目及模型名称与地址。准备任务不会调用教材生成模型；生成工具始终需要确认，不借用资源自动模式的持续授权。

默认只允许本机模型。使用远程服务商时，须明确允许把限定原文、可信画像、相关个人认知和学习记录发送到对应模型，并再次确认生成。此许可不授权抓取网页，也不改变概念补全的公开网页权限。

## 上下文与教材结构

`context.ts` 复用已有可信画像门控、知识点掌握度查询、认知库检索、资源显式反馈及学习事件存储。最近学习按真实完成时间选择，只承接当前根项目；其它计划即使记录更新更近，也不进入本次上下文。可选个人通道不可读时明确标记不可用，采用中性教学，不据此推断认知缺陷。

确认观点、未确认素材和复述记录各自编号，均不能成为教材事实来源。蓝图记录实际个人证据、原文来源、针对性讲解策略和章节对应关系；未表达只能作为待补充的教学覆盖，不直接判定不会或错误。个人原话和内部画像不写入可分享教材。

教材为 2–6 章，每章包括概念与机制、条件与边界、例子与反例、迁移练习、参考答案、自检和小结。章节引导句衔接当前教学目标与背景，不重新安排上一课的复习。Markdown 代码、表格、LaTeX 和引用注释按教学需要使用，不强制凑齐所有格式。

## 本地物料与质量门控

物料先复用限域 RAG 提供的线索，再用阶段二目录及深读接口读取选定章节。离线向量模型或索引不可用时退回目录选材，不依赖云端向量，也不把检索摘要当作已读原文。章节需读完；预算不足、来源失效和格式不支持会阻止发布。

本阶段上限是 12 份上传资料、12 个关联知识点、8 个目录阅读目标；上传资料原文包最多 72000 字符，合并知识点后最多 100000 字符。目录超过 120000 字符或单个知识点超过 18000 字符时要求缩小范围，不静默截断成“完整教材”。这些是教材模型的工作范围，不是资源工作台人工添加配额。

确定性检查覆盖目标与重点落章、真实编号、事实引用、来源授权、章节完整性、代码围栏和最终正文一致性。正文不接受可执行 HTML、受控项目块、任务指令或未采集的图片和链接；围栏内代码仅作为文字保留。模型输出截断不能进入发布。另有只读质量模型复核原文支持、条件与教学针对性；模型复核不是事实真伪的权威判定。

## 持久化与重试

私有任务保存在 `user-state/textbook-jobs/`，按阶段保存上下文、原文、蓝图、章节和质量结果。教材元数据只分享身份、章节与来源指针，不分享这些个人检查点。

批准绑定任务快照、项目规划内容、原始文件哈希、关联知识点版本及模型配置。执行前、物料完成后和提交前复核范围，模型每次调用也核验配置。规划内容的比较排除独立复盘与论证入口；新增折叠复盘可与教材一起保存，修改任务或项目正文则拒绝覆盖。一次生成使用开始时的一致上下文，遗忘率的自然变化不使最终提交失败。

发布复用 App 的串行学习写入和既有可恢复笔记快照事务，仅追加受管教材区域，保留外围正文、任务与个人记录。2026-10-06 复查修复了“先修改可见 notes，再等待保存”的问题：候选教材在落盘成功前不进入界面、notesRef 或索引；失败仍允许显式重试，不把可见候选误判成已生成。普通防抖保存及退出 flush 同样进入学习写入队列，并在实际执行时读取最新快照，避免旧防抖请求覆盖后来发布的教材。

保存期间新增独立复盘或其他笔记编辑时，发布器按最新可见快照重验、合并并再次保存；目标规划发生变化则拒绝覆盖。必要的纠正保存只使用当前最新快照，不回滚到首次基线。写入结束后主进程重读笔记并核验准确区域正文，才能返回 `published` 与 `saved=true`。文件中途故障不报成功，原有 journal 保留完整写入意图供恢复；不能把多文件事务描述为瞬时原子替换，也不宣称解决了所有独立直写入口或跨窗口冲突。

停止会取消在途教材模型请求并保留完成章节；已经开始的持久化安全收尾。项目查询可按私有目录找到重启后的待续任务，再次确认同一任务时只补未完成章节；来源或模型变化需重新准备。质量拒绝后再次确认，会带复核问题重写章节并重新检查。教材已落盘但任务回执中断时，仅核验完成，不再次生成或发布。重启不自动执行任务，需要重新确认。

## 验证结果与后续范围

`check:textbook-generation` 的 21 组检查通过，使用真实生产目录、深读、原文包、Agent 确认引擎、私有任务存储、生产发布适配器和临时文件笔记持久化，模型为脚本化响应，网络访问禁止。覆盖取消授权、同名项目、失败拒绝、重启续跑、范围变化、租约、迟到取消、质量修复、独立复盘合并、回执中断恢复及私人原话泄露门控；新增延迟保存失败不提前发布、不索引、同任务重试、保存中合并最新编辑、规划冲突纠正、Stop 与队列排序回归。

同时通过教材物料 11 组、折叠记录 13 组、冻结契约 12 组、Agent 基础与端到端、交互 19 组、顺序执行 11 组、资源浏览器、RAG 分源 8 组和 UI 契约检查；TypeScript、Web 与 Electron 构建通过。阶段零的两个旧版无来源教材缺口保持原基线，没有扩大排除规则隐藏它们。

真实模型对教学质量的表现、原生 Electron 确认与重启操作、跨窗口并发编辑仍待完成。多格式与章节续读已继续在[阶段四](personalized-textbook-phase-four.md)接入；复杂解析与受控网页补缺属于阶段五；已有教材的重写、追加和历史恢复属于阶段六。本阶段三本身不安装新渲染或爬虫依赖。
